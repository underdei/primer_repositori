# Ficha tecnica: Actividad en clase: Markdown y Git Local


## Objetivo
El objetivo de esta actividad sera editar un documento de formato Markdown con el Visual Studio Code, entender como funciona un repositorio local y practicar comandos como status o log.


## Materiales
Ordenador, github, git y el Visual Studio Code.
## Procedimiento

1. Crear el archivo  .md en Visual Studio Code.
2. Practicar Git en local
3. Crear versiones con commits utilizando Git.
4. Explicar el flujo de trabajo de git

## Explicacion git

El ciclo de un commit en Git tiene cuatro estados: primero editas un archivo como mi ficha-tecnica.md y queda en estado Modified, luego lo preparas con git add ficha-tecnica.md y pasa a Staged, después haces git commit -m "Completa procedimiento" y se guarda en el repositorio local en estado Committed, y finalmente con git push origin main se sincroniza Sync con GitHub.
